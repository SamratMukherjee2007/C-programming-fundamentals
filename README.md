## Getting Started

### Requirements

- A C compiler, such as GCC
- A code editor, such as Visual Studio Code

### Compile and Run

1. Clone this repository:

   ```bash
   git clone https://github.com/SamratMukherjee2007/C-programming-fundamentals.git
   ```

2. Open the repository folder in your terminal.

3. Navigate to the folder containing the program you want to run.

4. Compile the program using GCC:

   ```bash
   gcc hello_world.c -o hello_world
   ```

5. Run the compiled program.

   **Windows:**
   ```bash
   .\hello_world.exe
   ```

   **Linux:**
   ```bash
   ./hello_world
   ```

Replace `hello_world.c` with the filename of the program you want to execute.
