# 03 - Loop control statements

This folder contains C programs that use concepts of loops to solve problems with recurring steps.

These programs were created to practise applying loops to everyday scenarios, mathematical problems, and basic validation tasks.

## Programs

| No. | Program | Description |
|---|---|---|
| 1 | `armstrong_num.c` | Checks if a given number is armstrong number or not |
| 2 | `digit_counter.c` | Counts total number of digits in a number |
| 3 | `factorial.c` | Calculates factorial of a number using loops |
| 4 | `krishnamurty_num.c` | Checks if a given number is krishnamurty number or not |
| 5 | `mul_table.c` | Prints multiplication table of any number |
| 6 | `power_calc.c` | Calculate indices of any number without using pow function |
| 7 | `largest_of_3_nums.c` | Finds the largest among three numbers |
| 8 | `prime_num_check.c` | Check if a given number is prime or not |
| 9 | `reverse_num.c` | Prints reverse of a given number |
| 10 | `sum_of_digits.c` | Calculate sum of digits of any given number |
| 11 | `sum_of_natural_nums.c` | Calculate sum of first n natural numbers |

## Concepts Practised

- `for` loop control statement
- `while` loop statement
- Nested loop statements
- Iteration in loops
- Handling different edge cases
- Basic validation and mathematical logic

*The exact concepts used may vary between programs.*

## How to Run

Navigate to this folder and compile the program you want to run:

```bash
gcc factorial.c -o factorial
```

Run the program:

**Windows:**
```bash
.\factorial.exe
```

**Linux:**
```bash
./factorial
```

Replace `factorial.c` with another filename to run a different program.

## Learning Objectives

- Understand loop control program execution
- Combine conditional statements with loop control statements
- Solving problems using nested loops
- Handle different input scenarios
- Improve logical thinking and problem-solving skills
