# 01 - C Programming Basics

This folder contains beginner-level C programs created to understand the basic syntax, input/output operations, variables, arithmetic expressions, and program structure.

## Programs

| No. | Program | Description | Concepts Used |
|---|---|---|---|
| 1 | `hello_world.c` | Prints a Hello World message | `printf()`, basic syntax |
| 2 | `simple_addition.c` | Adds two numbers | Variables, input/output, arithmetic |
| 3 | `simple_calculator.c` | Performs basic arithmetic calculations | Operators, input/output, decision-making |
| 4 | `area_of_circle.c` | Calculates the area of a circle | Variables, constants, arithmetic |
| 5 | `swapping_two_nums.c` | Swaps the values of two numbers | Variables, assignment |

## How to Run

Make sure GCC is installed on your system.

Navigate to this folder and compile the required program:

```bash
gcc hello_world.c -o hello_world
```

Run the program:

**Windows:**
```bash
.\hello_world.exe
```

**Linux:**
```bash
./hello_world
```

Replace the filename with the program you want to execute.

## Learning Objectives

- Understand the basic structure of a C program
- Learn how to display output and accept user input
- Work with variables and data types
- Perform arithmetic operations
- Develop familiarity with compiling and running C programs
