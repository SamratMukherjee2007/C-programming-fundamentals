# 02 - Conditional Statements

This folder contains C programs that use conditional statements to solve decision-making problems.

These programs were created to practise applying conditions to everyday scenarios, mathematical problems, and basic validation tasks.

## Programs

| No. | Program | Description |
|---|---|---|
| 1 | `atm_withdrawl.c` | Simulates an ATM withdrawal |
| 2 | `banking_system.c` | Implements basic banking-related logic |
| 3 | `coordinate_system.c` | Determines the position of a point using coordinates |
| 4 | `date_validator.c` | Validates a given date |
| 5 | `electric_bill_calc.c` | Calculates an electricity bill |
| 6 | `even_odd_checker.c` | Checks whether a number is even or odd |
| 7 | `largest_of_3_nums.c` | Finds the largest among three numbers |
| 8 | `leap_year.c` | Determines whether a year is a leap year |
| 9 | `student_grading_system.c` | Assigns a grade based on marks |
| 10 | `time_validator.c` | Validates a given time |
| 11 | `triangle_analyser.c` | Analyses a triangle using the given values |
| 12 | `voter_eligibility.c` | Checks voting eligibility based on age |

## Concepts Practised

- `if` statements
- `if-else` statements
- `else-if` ladders
- Nested conditional statements
- Logical operators: `&&`, `||`, `!`
- Relational operators: `>`, `<`, `>=`, `<=`, `==`, `!=`
- Decision-making using user input
- Basic validation and mathematical logic

*The exact concepts used may vary between programs.*

## How to Run

Navigate to this folder and compile the program you want to run:

```bash
gcc even_odd_checker.c -o even_odd_checker
```

Run the program:

**Windows:**
```bash
.\even_odd_checker.exe
```

**Linux:**
```bash
./even_odd_checker
```

Replace `even_odd_checker.c` with another filename to run a different program.

## Learning Objectives

- Understand how conditional statements control program execution
- Combine multiple conditions to solve problems
- Apply logical and relational operators
- Handle different input scenarios
- Improve logical thinking and problem-solving skills
